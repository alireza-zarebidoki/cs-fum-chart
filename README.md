## ✨ ویژگی‌ها

- **۸۲ درس کامل**، هرکدام با هدف، شایستگی، سرفصل، روش تدریس، روش ارزیابی و منابع — طبق آیین‌نامه‌ی مصوب.
- **گراف پیش‌نیاز/هم‌نیاز** به سبک `git log --graph`، با هایلایت زنجیره‌ی مرتبط هنگام هاور/فوکوس و امکان انتخاب محدوده (دروس اصلی / همه‌ی ۸۲ درس / یک خوشه‌ی خاص).
- **چارت پیشنهادی ۸ ترمه** برای چیدمان دروس.
- **۸ خوشه‌ی دانشی** (هوش مصنوعی، یادگیری ماشین، امنیت، بیوانفورماتیک و…) با صفحه‌ی اختصاصی برای هرکدام.
- **فهرست کامل + جستجو و فیلتر** (نوع درس، خوشه، حل تمرین).
- **تم تاریک/روشن**، فونت فارسی Vazirmatn + فونت کد JetBrains Mono.
- **کاملاً استاتیک و بدون وابستگی** — روی هر هاست استاتیکی (GitHub Pages، Netlify، Vercel، Cloudflare Pages، یا هاست اشتراکی Apache) قابل‌انتشار است.
- **معماری Content-Driven**: هیچ متن مربوط به دروس در HTML/JS هاردکد نشده؛ همه‌چیز از `data/*.json` خوانده می‌شود.

## 🚀 اجرای محلی

مرورگرها به دلایل امنیتی (CORS) اجازه‌ی `fetch` مستقیم فایل‌های JSON را از
`file://` نمی‌دهند، پس پروژه باید با یک سرور سبک محلی اجرا شود. هر یک از روش‌های زیر کافی است:

```bash
# با پایتون (از پیش روی اغلب سیستم‌ها نصب است)
python3 -m http.server 8000
# سپس در مرورگر باز کنید: http://localhost:8000
```

```bash
# یا با Node.js
npx serve .
```

یا با افزونه‌ی **Live Server** در VS Code (کلیک راست روی `index.html` ← Open with Live Server).

برای بررسی یکپارچگی داده‌ها (پیش‌نیازهای ناموجود، چرخه، sitemap قدیمی، لینک شکسته):

```bash
node scripts/validate-data.js
```



## 🗂 کار با داده‌ها

### افزودن یک درس جدید

یک آبجکت جدید به آرایه‌ی `courses` در `data/courses.json` اضافه کنید:

| کلید | توضیح |
| --- | --- |
| `id` | شناسه‌ی یکتای لاتین، برای URL (`course.html?id=...`) |
| `titleFa` / `titleEn` | نام درس |
| `type` | یکی از: عمومی، پایه، تخصصی الزامی، تخصصی اختیاری، مهارتی – اشتغال‌پذیری |
| `hasExerciseSession` | `true` / `false` |
| `units` / `hours` | `{theory, practical, total}` |
| `prerequisites` / `corequisites` | آرایه‌ای از `id` دروس دیگر (برای لینک‌شدن خودکار در گراف و صفحات جزئیات) |
| `clusters` | آرایه‌ای از `id` خوشه‌های دانشی (از `clusters.json`) |
| `goals`, `competencies`, `syllabus`, `teachingMethods`, `references` | آرایه‌ای از رشته‌ها |
| `evaluation` | `{continuousMax, midtermMax, finalMin, finalNote, projectMax, projectNote}` |
| `equipment` | رشته یا `null` |
| `featured` | `true` برای نمایش در صفحه‌ی اصلی (لیست منتخب) |
| `stub` | `true` برای درسی که فقط به‌عنوان پیش‌نیاز لازم است ولی هنوز سرفصل کامل ندارد |

به‌محض ذخیره‌ی فایل و رفرش صفحه، درس جدید در فهرست، فیلترها، صفحه‌ی جزئیات و گراف
پیش‌نیاز ظاهر می‌شود — بدون نیاز به تغییر در HTML/JS.

### افزودن/ویرایش خوشه‌های دانشی

در `data/clusters.json`، هر خوشه یک `id`، `nameFa`، `nameEn` و `color` (هگز، برای
نقطه‌ی رنگی و لبه‌ی کارت) دارد. فهرست و تعداد دروس هر خوشه به‌طور کامل و خودکار
از `courses.json` مشتق می‌شود — نیازی به فهرست دستی نیست.

### ویرایش چارت پیشنهادی ترمی

فقط `data/semester-plan.json` را ویرایش کنید — هیچ کد UI نیازی به تغییر ندارد.
هر آیتم یا به یک `id` واقعی از `courses.json` اشاره می‌کند، یا یک جای‌خالی
(`placeholder`) مثل «عمومی» یا «اختیاری» است برای دروسی که سرفصل اختصاصی مشخصی
ندارند.

### به‌روزرسانی نقشه‌ی سایت

هر بار درس یا خوشه‌ی جدیدی اضافه کردید:

```bash
node scripts/generate-sitemap.js
```

این دستور `sitemap.xml` را از روی `data/*.json` بازتولید می‌کند (بدون نیاز به
`npm install` — فقط از ماژول‌های داخلی Node استفاده می‌شود).

## 📊 وضعیت داده‌ی فعلی و روش استخراج

این نسخه شامل **تمام ۸۲ درسی است که در آیین‌نامه سرفصل کامل دارند**: ۶ درس پایه،
۲۷ درس تخصصی الزامی، ۴ درس مهارتی–اشتغال‌پذیری، و تمام ۴۵ درس اختیاری منحصربه‌فرد
در ۸ خوشه‌ی دانشی + بدون‌خوشه — هرکدام با هدف، شایستگی، سرفصل، روش تدریس، روش
ارزیابی و منابع کامل.

**دروسی که در این نسخه نیستند:** ۲۲ واحد دروس عمومی (فارسی، معارف اسلامی، زبان
خارجی، تربیت‌بدنی و مانند این‌ها). این‌ها در سند آیین‌نامه سرفصل اختصاصی ندارند —
طبق برنامه‌ی عمومی سراسری دانشگاه‌ها تدریس می‌شوند — پس عمداً fabricate نشدند.

استخراج مستقیم متن PDF منبع اصلی (`files/curriculum.pdf`) برای بخش‌های فارسی این
سند یک باگ فونت داشت (برخی حروف مثل «د» در وسط کلمه حذف می‌شدند، یا حروف شبیه‌به‌هم
مثل «ط/ع» جابه‌جا می‌شدند). برای دور زدن این مشکل، تمام ۱۰۷ صفحه‌ی مربوط به سرفصل
دروس با OCR فارسی (Tesseract) در وضوح ۲۰۰dpi پردازش شد و محتوای متنی (اهداف، سرفصل،
روش تدریس) از OCR استخراج شد؛ جدول‌های عددی (واحد، ساعت، پیش‌نیاز) و منابع انگلیسی
از استخراج مستقیم PDF گرفته شدند چون در آن‌ها دقیق‌تر بودند. نتیجه با جمع واحدهای
رسمی هر دسته (پایه = ۲۰ واحد، تخصصی الزامی = ۷۳ واحد / ۱۲۱۶ ساعت) تطبیق داده و
تأیید شد.

> **محدودیت شناخته‌شده:** با وجود این دو مرحله‌ی تمیزکاری، ممکن است در متن
> سرفصل/اهداف برخی دروس هنوز غلط‌های تایپی جزئی OCR باقی مانده باشد (مثلاً یک
> نویسه‌ی نادرست در یک اصطلاح ریاضی نادر). محتوای اصلی و ساختار هر درس تأیید شده،
> اما برای مرجع رسمی دقیق، بهتر است با نسخه‌ی اصلی PDF (`files/curriculum.pdf`)
> مقابله شود.

## 🎨 هویت بصری

- فونت فارسی: **Vazirmatn** (از jsDelivr، نسخه‌ی پین‌شده `v33.003`) — فونت لاتین/کد: **JetBrains Mono** (از Google Fonts).
- تم پیش‌فرض: دارک، با ایده‌ی «ویرایشگر کد» — خوشه‌های دانشی مانند رنگ‌های
  syntax-highlighting یک تم ویرایشگر کد در نظر گرفته شده‌اند.
- عنصر امضا (signature element): گراف پیش‌نیازها به سبک `git log --graph` —
  دروس به‌صورت گره و پیش‌نیازها به‌صورت یال، بر اساس عمق زنجیره چیده می‌شوند.
- حالت روشن نیز پشتیبانی می‌شود (دکمه‌ی بالای صفحه).
- دسترس‌پذیری: outline قابل‌مشاهده برای فوکوس کیبورد، پشتیبانی از
  `prefers-reduced-motion`، و ناوبری کامل با کیبورد.

## 🔍 سئو (SEO)

سایت روی دامنه‌ی `chart.csfum.ir` (و به‌طور موازی روی GitHub Pages) منتشر می‌شود؛
`chart.csfum.ir` دامنه‌ی canonical در نظر گرفته شده تا محتوای تکراری بین دو آدرس
مشکل ایجاد نکند.

- **`robots.txt` / `sitemap.xml`**: در ریشه‌ی پروژه هستند. `sitemap.xml` را دستی
  ویرایش نکنید — همیشه با `node scripts/generate-sitemap.js` بازتولید کنید.
- **`CNAME`**: برای اتصال دامنه‌ی اختصاصی به GitHub Pages (تنظیمات Settings →
  Pages در گیت‌هاب هم باید این دامنه ثبت شود).
- **عنوان/توضیحات/canonical/Open Graph**: صفحات ثابت (`index.html`,
  `all-courses.html`, `semester-plan.html`) این‌ها را به‌صورت استاتیک در `<head>`
  دارند. صفحات الگو-محور (`course.html`, `cluster.html`) یک نسخه‌ی fallback
  استاتیک دارند که پس از اجرای جاوااسکریپت (`js/seo.js` + `updateSEO()` در
  `course-detail.js`/`cluster-detail.js`) با عنوان/توضیح واقعی همان درس یا خوشه
  جایگزین می‌شود.
- **JSON-LD (Structured Data)**: `WebSite` + `EducationalOccupationalProgram` در
  صفحه‌ی اصلی، `Course` + `BreadcrumbList` در صفحه‌ی هر درس، `ItemList` +
  `BreadcrumbList` در صفحه‌ی هر خوشه، و `ItemList` در فهرست کامل دروس — همه
  به‌صورت پویا با `injectJSONLD()` تزریق می‌شوند.
- **`og-image.png`** (۱۲۰۰×۶۳۰): تصویر پیش‌نمایش لینک در شبکه‌های اجتماعی.

> ⚠️ **محدودیت مهم:** محتوای اصلی صفحات `course.html`, `cluster.html`,
> `semester-plan.html`, `all-courses.html` در HTML خام وجود ندارد و فقط بعد از
> اجرای جاوااسکریپت از `data/*.json` ساخته می‌شود. گوگل معمولاً جاوااسکریپت را
> اجرا می‌کند ولی با تأخیر (رندر در یک پاس دوم)؛ بسیاری از ربات‌های دیگر آن را
> کامل اجرا نمی‌کنند. برای ایندکس‌شدن سریع‌تر و پایدارتر — به‌خصوص برای رتبه
> گرفتن روی نام تک‌تک درس‌ها — بهترین قدم بعدی، **پیش‌رندر کردن HTML واقعی هر
> صفحه در زمان build (Static Site Generation)** است، نه فقط در مرورگر. این یک
> تغییر معماری جدا و بزرگ‌تر است.

## 🔒 امنیت

سایت کاملاً استاتیک است (بدون سرور/دیتابیس/فرم)، پس بیشتر آسیب‌پذیری‌های کلاسیک
وب (SQL Injection، CSRF، Auth) اصلاً موضوعیت ندارند. با این حال این چند مورد
به‌عنوان دفاع در عمق اعمال شده:

- **`js/digits.js` → `esc()`**: قبل از اینکه هر متن آزاد (عنوان، سرفصل، یادداشت،
  منابع و…) داخل `innerHTML` قرار بگیرد، از این تابع عبور می‌کند تا کاراکترهای
  `& < > " '` به‌صورت HTML entity نمایش داده شوند. چون همه‌ی داده‌ها از
  `data/*.json` می‌آیند که مستقیم توسط نگهدارنده‌ی مخزن ویرایش می‌شوند، این لایه
  امروز محافظت در برابر مهاجم بیرونی نیست — بیمه‌ای است برای روزی که این JSONها
  از یک فرم، CMS چندنفره یا منبع خارجی پر شوند.
  **نکته برای توسعه‌ی بعدی:** هر رندر تازه‌ای که به `innerHTML` متن آزاد از JSON
  اضافه می‌کنید، حتماً با `esc(...)` بپیچید (الگوی `esc(fa(course.something))`
  را در بقیه‌ی فایل‌های `js/*.js` ببینید).
- **Content-Security-Policy**: در `<head>` همه‌ی صفحات یک متاتگ CSP اضافه شده
  (`script-src 'self'` و غیره) تا حتی اگر یک روز اسکریپت خارجی/inline ناخواسته
  اضافه شد، به‌طور پیش‌فرض اجرا نشود.
- فونت از `cdn.jsdelivr.net` روی یک نسخه‌ی مشخص (`v33.003`) پین شده، نه `latest`.
  برای یک لایه‌ی دفاعی دیگر می‌توان فونت را self-host کرد یا با
  `integrity="sha384-..."` (Subresource Integrity) این لینک را قفل کرد.

## ⚠️ محدودیت‌های شناخته‌شده

- چک‌لیست سرفصل‌ها (تیک‌زدن) در `localStorage` مرورگر ذخیره می‌شود؛ بین دستگاه‌ها
  همگام نمی‌شود.
- گراف پیش‌نیاز فعلاً فقط دروسی را نشان می‌دهد که در `courses.json` تعریف
  شده‌اند (نه کل ۱۳۸ واحد برنامه).
- محتوای صفحات الگو-محور client-side رندر می‌شود (نگاه کنید به بخش
  [سئو](#-سئو-seo)).

## 🤝 مشارکت

پول‌ریکوئست و ایشو خوش‌آمد است، به‌خصوص برای:

- تصحیح اشتباهات تایپی/OCR در سرفصل، اهداف یا منابع دروس (`data/courses.json`)
- افزودن یا اصلاح پیش‌نیاز/هم‌نیاز دروس
- بهبود دسترس‌پذیری (accessibility) و پرفورمنس

جزئیات کامل در [CONTRIBUTING.md](CONTRIBUTING.md) آمده است. به‌طور خلاصه: پروژه را طبق
[اجرای محلی](#-اجرای-محلی) تست کنید، `node scripts/validate-data.js` را اجرا کنید و اگر درس یا
خوشه‌ای اضافه/حذف کردید `node scripts/generate-sitemap.js` را هم اجرا و `sitemap.xml` تازه را کامیت کنید.
مشارکت‌کنندگان ملزم به رعایت [آیین‌نامه‌ی رفتار](CODE_OF_CONDUCT.md) هستند.
