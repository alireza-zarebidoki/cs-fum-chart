# سیاست امنیتی

این پروژه یک سایت **کاملاً استاتیک** است (بدون سرور، پایگاه‌داده، فرم یا احراز هویت)، ولی اگر مشکلی امنیتی پیدا کردید — مثلاً XSS از طریق داده‌ی JSON یا ضعف در هدرها — ممنون می‌شویم مسئولانه گزارش دهید.

## نحوه‌ی گزارش

لطفاً مشکل امنیتی را **در Issue عمومی ننویسید**. از این لینک استفاده کنید:

**[گزارش خصوصی آسیب‌پذیری](https://github.com/alireza-zarebidoki/cs-fum-chart/security/advisories/new)**
(یا Security ← Report a vulnerability).


شرح مشکل، مراحل بازتولید و تأثیر احتمالی را بنویسید. تلاش می‌کنیم ظرف چند روز پاسخ دهیم.

## نسخه‌های پشتیبانی‌شده

فقط آخرین نسخه‌ی شاخه‌ی `main` پشتیبانی می‌شود.

## English

# Security Policy

This project is a **fully static** site (no server, database, forms or authentication), but if you find a security issue — for example XSS through JSON data or a weakness in headers — we'd appreciate a responsible report.

## How to report

Please **do not open a public issue**. Use:

**[Report a vulnerability privately](https://github.com/alireza-zarebidoki/cs-fum-chart/security/advisories/new)**
(or Security → Report a vulnerability).

Describe the problem, the steps to reproduce it and its possible impact. We try to reply within a few days.

## Supported versions

Only the latest version of the `main` branch is supported.
